# strava-bot

Post strength workouts logged in the Strong iOS app to Strava, automatically, with an LLM-generated title and description.

This repo is spec-first: `app/`, `scripts/`, and `tests/` don't exist yet. The implementation spec lives under [`docs/`](docs/), split into small files for progressive disclosure.

- [docs/CONSTRAINTS.md](docs/CONSTRAINTS.md) — non-negotiable rules; read before touching `app/`.
- [docs/STATUS.md](docs/STATUS.md) — current build progress and open items.
- [docs/PLANNING.md](docs/PLANNING.md) — index into the full spec and the build order.
- [docs/glossary.md](docs/glossary.md) — domain terms.
